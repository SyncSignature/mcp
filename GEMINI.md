# SyncSignature

Before calling any SyncSignature tool, read https://mcp.syncsignature.com/skills and follow it.
Ask the user to confirm before any tool that creates, changes or deletes data (create_*, update_*, delete_*, add_teammates_to_group, remove_teammates_from_group, pause_campaign, resume_campaign).
Campaigns are created in the SyncSignature app, not through these tools.
SyncSignature does not route or read email.
